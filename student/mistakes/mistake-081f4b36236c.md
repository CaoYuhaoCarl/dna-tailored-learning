# 错题记录

- 学科：英语
- 题型：语法填空
- 原题：I ____ (read) this book three times.
- 我的答案：am reading
- 正确答案：have read
- 正确思路："three times"表示从过去到现在一共发生的次数，应用现在完成时。主语是I，用have，read的过去分词仍是read，故填have read。
- 错因：误用了现在进行时，没有识别出"three times"这一表示完成次数的线索。
- 知识点：现在完成时（have/has + 过去分词）
- 下次提醒：看到"three times"、"already"、"just"、"ever"等词时，先考虑现在完成时。
