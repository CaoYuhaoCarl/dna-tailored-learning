# 错题记录

- 学科：英语
- 题型：单词拼写
- 原题：I stayed at home b_______ it was raining.
- 我的答案：becuase
- 正确答案：because
- 正确思路：because 的正确拼写是 b-e-c-a-u-s-e，注意中间是 c-a-u，不是 c-u-a。
- 错因：把 because 中的 c-a-u 误写成 c-u-a，属于元音字母顺序拼写错误。
- 知识点：because 的拼写
- 下次提醒：写 because 时默念 b-e-c-a-u-s-e，重点检查中间的 c-a-u 顺序。
