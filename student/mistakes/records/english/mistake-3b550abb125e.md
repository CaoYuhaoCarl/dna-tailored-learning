# 错题记录

- 学科：英语
- 题型：单词拼写
- 原题：We should protect the e________ from pollution.
- 我的答案：enviroment
- 正确答案：environment
- 正确思路：environment 的正确拼写是 e-n-v-i-r-o-n-m-e-n-t，中间有 r-o-n，不是 r-o。
- 错因：漏写了 environment 中的字母 n，把 r-o-n 误写成 r-o。
- 知识点：environment 的拼写
- 下次提醒：写 environment 时注意中间是 r-o-n，不要漏掉 n。
