# 错题记录

- 学科：英语
- 题型：语法填空
- 原题：She ____ (go) to the library yesterday.
- 我的答案：has gone
- 正确答案：went
- 正确思路："yesterday"是明确的过去时间点，表示过去某个具体时间发生的动作，应用一般过去时，go 的过去式是 went。
- 错因：误用了现在完成时 has gone，没有识别出"yesterday"这一一般过去时的标志词。
- 知识点：一般过去时（动词过去式）
- 下次提醒：看到 yesterday、last week、ago 等明确过去时间词时，用一般过去时。
