# 整理错题

## Step 1：识别并复用已有信息

先从当前消息和完整对话历史中提取已经出现的信息，不要重复询问学生已经提供或已经确认的内容。

需要整理的字段包括学科、题型、原题、学生原答案、正确答案、正确思路、错因、知识点和下次提醒。

原题和学生原答案是保存所需的最少信息。

如果这两项缺失，每轮只询问一项缺失信息。

## Step 2：决定是立即整理还是继续教学

如果学生明确要求“整理”“收集”“归档”或“保存”，或者直接提交结构化错题记录，使用已有信息立即整理，不要强制学生继续回答教学问题。

尚未确认的分析字段统一填写“待补充”，不得编造。

如果学生希望先弄懂题目，可以沿用一次只问一个问题的苏格拉底方式。

一旦正确答案已经确认，直接用对话中已有依据总结正确思路、错因、知识点和下次提醒，不再追加与保存无关的反思问题。

## Step 3：调用工具真实保存

整理好字段后调用 `save_mistake`。

工具参数与内容字段对应如下：

- `subject`：学科。
- `problem_type`：题型。
- `original_question`：原题。
- `student_answer`：学生原答案。
- `correct_answer`：正确答案。
- `correct_reasoning`：正确思路。
- `error_reason`：错因。
- `knowledge_point`：知识点。
- `next_reminder`：下次提醒。

暂时未知的字段传入“待补充”。

工具会生成以下 Markdown，并将文件写入 `student/mistakes/`：

```markdown
# 错题记录

- 学科：<学科>
- 题型：<题型>
- 原题：<题目原文>
- 我的答案：<学生原答案>
- 正确答案：<正确答案>
- 正确思路：<学生确认后的思路>
- 错因：<本次错误原因>
- 知识点：<对应知识点>
- 下次提醒：<一句可执行的检查方法>
```

## Step 4：根据工具结果回复

只有 `save_mistake` 返回“保存成功”或“已经保存”后，才能告诉学生已经保存，并附上工具返回的文件路径。

如果工具返回“保存失败”，如实告诉学生原因，不得声称已经写入磁盘。

完成保存后结束本次整理任务，不要再附加一个苏格拉底问题。
