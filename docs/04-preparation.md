## 二、 核心资产：申请大模型 API Key

本课程将统一使用 **DeepSeek** 大模型作为 AI Agent 大脑。API Key 就像是激活 AI 大脑的“钥匙”，请您务必在课前协助孩子申请好。

1. **访问官网**：在浏览器中打开 DeepSeek 开放平台官网(https://platform.deepseek.com/api_keys)。
2. **注册账号**：使用您的手机号进行注册并登录。
3. **生成 Key**：进入“API keys”菜单，点击“创建 API Key”。
4. **妥善保存**：系统会生成一串由英文字母和数字组成的密钥（如 `sk-xxxxxx...`）。**请注意，该密钥只显示一次，请务必将其复制并保存在电脑桌面上的一个文本文件中，上课时需要用到。**

#### **VS Code 安装和配置**

VS Code简介：
是由微软开发的一款免费、开源的跨平台代码编辑器。它兼容 Windows、macOS 、Linux，支持多种编程语言（如 JavaScript、Python、C++、Java、Go 等）

VS Code 是什么？
想象一下，你有一支神奇的彩色笔，能帮你写字、画画，还能把写好的字自动检查有没有错。VS Code 就是这样一支“电脑上的彩色笔”，专门用来写程序（也就是让电脑听指令的语言）。它能干什么？

写代码	像在笔记本上写作业，VS Code 会把关键字用不同颜色标出来，让你一眼就能看出哪些是动词、哪些是名词。
自动补全	当你写到一半，VS Code 会猜出你想写的下一个词，像老师提前把答案写在黑板上，帮你省时间。
检查错误	它会像小侦探一样，找出你写错的地方并提示你改正。
运行程序	你可以直接在它里面点一下“开始”，就像按下玩具的开关，让你的程序马上跑起来。
保存和分享	写好的代码可以保存到电脑里，或者和小伙伴一起分享，就像把作业本交给老师或同学。
装插件	VS Code 可以装很多“小工具”，比如帮你画图、翻译、写数学公式，像给你的彩色笔加上更多颜色和功能。
