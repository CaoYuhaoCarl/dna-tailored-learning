课程核心理念：
从抄写答案，到定义问题；
从只看对错，到看见过程；
从会用工具，到会造工具。


---
课程内容：
【第1讲】AI 提示词 -> AI 技能/插件
【1-1】专属苏格拉底式 AI 学习导师
- 实操案例：你的专属苏格拉底式 AI 学习导师
- 课程目的：理解Prompt对当前LLM AI的作用，以及如何设计一个好的Prompt。
- 实操步骤：学生将学习拆解提示词的底层结构，编写一段长效约束指令，设定AI为“只启发、绝对不给最终答案的特级教师”。输入一道复杂的数学或英语题后，测试AI是否能通过类比和分步反问，引导自己一步步找出逻辑漏洞，完成从“直接拍题抄答案”到“独立思考推导”的思维逆转。
- 学生收货：AI 提示词 ｜运用苏格拉底式提示词模板，让AI作为导师反问并引导拆解复杂的理科难题。

【1-2】构建私人的英语AI知识地图
- 实操案例：构建私人的英语AI知识地图
- 课程目的：理解Skill的作用以及原理，能写出一个标准的Skill。
- 实操步骤：学生将学习如何为智能体添加“联网搜索”与“思维导图/图表生成”技能/插件。以庞杂的历史事件（如二战时间线）或生物过程（如光合作用）为例，要求AI先自动提取核心概念，再调用插件一键生成脉络清晰的思维导图或结构图，让抽象的文字瞬间转化为直观的视觉化复利学习资产。
- 学生收货：AI 技能/插件 | 跨越纯文本的交互边界，为AI挂载外援技能（Skill），将各个学科复杂的知识体系、知识点形成可视化的结构化知识图谱。

【第2讲】Agent -> Agent Team
【2-1】搭建“有证据、可核验”个性化学科辅导Agent
- 实操案例：搭建“有证据、可核验”个性化学科辅导Agent
- 课程目的：理解AI chatbot和Agent的区别，自己能搭出Agent。
- 实操步骤：针对大模型做题容易胡编乱造（产生幻觉）的痛点，学生将官方教材或课程知识包上传至知识库中，并为Agent配置检索逻辑：强制AI在回复前，必须优先在知识库中精准匹配正确的定理公式，回答中标注来源编号，并运行引用检查器验证每个结论，确保输出结果有证据、可核验。
- 学生收货：AI Native Agent | 从使用者变身开发者，导入教材或个人笔记，构建专属的本地知识库（llm-wiki知识库）。

【2-2】知识漏洞雷达Agent系统
- 实操案例：知识漏洞雷达Agent系统
- 课程目的：理解Agent系统及对Agent的编排，有一个初步的框架式的理解。
- 实操步骤：老师现场运行一条完整的教育应用流水线：节点一解析课程样例错题（无姓名、无人脸）；节点二运用大语言模型深度剖析导致做错的底层逻辑盲区；节点三根据分析结果，自动生成一道知识点相同但场景不同的巩固题。学生观察三个节点的状态传递，填写三张 Agent 配置卡，生成自己的流程设计图，并为流程补充失败处理、人工复核点和测试样例，实现“拍照诊断-错因分析-举一反三”的个性化学习闭环设计。
- 学生收货：AI Agent Team | 多智能体编排，通过自然语言描述，设计集“错题输入、错因分析与同等难度个性化出题”于一体的Native Agent应用（自定义Workflow），交付 team_blueprint.json、流程图 PNG 和测试清单。

课程总结：

两天时间，把 AI 从“答案机器”变成孩子终身学习的Copilot。

孩子不仅学会使用 AI，更学会拆解问题、设计流程、验证结果，并在复盘中看见自己的思维盲区，初步建立工程化思维、系统化思维和元认知能力。

未来人才，不是“会不会问 AI”，而是能不能把 AI 嵌入自己的判断、执行和迭代流程中，让 AI 成为个人能力结构的一部分，把自己和agent编排到一个持续迭代的系统中。
